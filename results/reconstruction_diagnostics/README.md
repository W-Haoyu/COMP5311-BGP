# 相关组重构误差诊断

## 目标与运行

保持 `results/reconstitution_v2_0015/rules.json` 的逐前缀 VP 过滤规则不变，仅比较相关组训练长度和是否按经验置信度抑制推断。在 coding 目录执行：

```sh
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m unittest discover -s tests -v
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python src/reconstruction_diagnostics.py
```

程序覆盖本目录 `summary.csv`、`prefixes.csv`、`metadata.json`。训练分别使用 2023-09-01 00:00 和 00:00+00:05 UTC rrc00 更新文件；测试使用 00:15、00:20、00:25 三个五分钟文件。数据：https://data.ris.ripe.net/rrc00/2023.09/ 。00:15 和 00:20 已用于上阶段实验，00:25 为本次新增留出数据。两个训练长度使用的 VP 规则都来自原先五分钟训练，故本实验隔离的是相关组预测方式，不是重新训练过滤器。

## 方法

对于每一训练特征，计算其所属相关组中权重最大的组的权重，除以该特征所属的所有组权重之和，记为经验置信度。只有置信度不低于阈值才展开该组；否则只保留观测到的记录。阈值 0 是此前按最高权重组展开的基线；0.7、0.9、1 是诊断性试验，不是论文 GILL 的参数。历史窗口并不独立，权重比不是经校准的事件概率，低频组合置信度也可能等于 1。

真实记录与重构记录按 VP、AS_PATH、community 完全一致和时间差不超过 100 秒一对一匹配；完全相同时间/特征的预测合并。召回=命中数/真实前缀级记录数，精确=命中数/去重预测数。两个都包含直接保留记录，因此这不是论文假阳性率；若直接保留有完全相同的重复记录，去重后无法全部匹配。只评估原先选定的 20 个前缀、普通 IPv4 AS_SEQUENCE announcement，不包括撤销、IPv6、RIB 中所有路径、跨前缀规则或锚点。MRT 文件中的解码错误计入 metadata。

## 发现与边界

新增 00:25 测试中，五分钟训练、无阈值的召回/精确约 77.39%/16.18%，阈值 0.7 为 54.35%/41.26%；后者把预测数从 63,146 降至 17,396，但也漏掉更多真实记录。十分钟训练、无阈值约 79.82%/14.93%，阈值 0.7 约 40.98%/37.51%。两种训练长度的保留记录均为 478/13,204；不能将阈值效果视为过滤器数据量变化。

阈值在这批数据中表现为召回和精确的权衡，并非全局最优。延长到十分钟使该窗口中未见过的保留特征从 133 减少到 95，却未稳定改善精确率。测试 0.7、0.9 和 1.0 的结果相同是此样本上计算结果，不意味着这些阈值普遍等价；没有按 00:25 数据挑选阈值。本实验不改变 VP 规则，也没有用阈值重做训练选择或重新评估链路覆盖，不能说提高了论文所要求的过滤效果。事件组仍是简化的非重叠窗口，训练窗口仍远短于论文，不是完整 GILL 复现。
