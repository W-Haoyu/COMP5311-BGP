# 扩展实验：两个收集器与两个时间窗口

## 目的和范围

这是针对 AS 链路覆盖率的探索性实验，不是 GILL 实现，也不是对论文表 2 的直接复现。使用 RIPE RIS rrc00 和 rrc01 的 2023-09-01 历史更新；每个收集器分别用 00:00 文件训练、00:10 文件测试，以及 01:00 文件训练、01:10 文件测试，时间均为 UTC。来源：https://data.ris.ripe.net/ 。文件名为开始时间；两次训练并不使用全部历史更新。

## 运行

在 coding 目录下执行：

```sh
.venv/bin/python src/multicase.py
```

脚本依赖 `src/experiment.py` 的解析函数及 `mrtparse==2.2.0`；会覆盖 `results/multicase/` 下同名结果。数据文件存于 `data/rrc00/` 和 `data/rrc01/`。

## 方法

仅基于训练集，按每条训练 UPDATE 可带来的新 AS 链路数贪心排序 VP。基线使用种子 42，100 个随机排列。测试时以测试集所有 VP 的 UPDATE 消息总数的 5%、10%、20%、40% 为共同上限，按各自排序依次加入能放入的完整 VP，跳过超过剩余上限的 VP。相同上限并不保证实际成本相同。此过程使用了各 VP 在测试窗口的实际消息数，属于事后预算匹配，包含对未来成本的了解，不是在线可执行的采样策略。排序和链路收益不使用测试集，但测试期成本参与筛选。

覆盖率分母是相应测试文件所有 VP 中可从普通 IPv4 announcement、仅含 AS_SEQUENCE 的路径提取的不同无向 AS 链路数；没有 RIB 数据，并不能代表真实互联网全量拓扑。预算计入所有解析出的 UPDATE 消息，包括撤销和 IPv6，链路指标只使用符合条件的 IPv4 announcement。只有训练和测试窗口共同出现的 VP 可被选择；测试期其他 VP 的链路仍包含在分母中。

## 输出

- `runs.csv`：每个场景、预算、算法和随机重复的实际成本与覆盖率。
- `comparison.csv`：贪心与随机平均值及随机实验的第 5 / 95 百分位（100 个样本的顺序统计量）。
- `metadata.json`：VP、解析数量及链路参考集合统计。

## 局限

数据只覆盖同一天的两个收集器、每个仅两个短测试窗口；样本之间可能相关。共同上限不是完全相等的数据成本；测试数据提供实际成本是事后假设，未来在线实验应使用训练期估计或流式预算控制。随机基线的范围表示随机选择之间的差异，不是跨日期统计置信区间。选 VP 的目标正是拓扑链路，因此表现不能推及 MOAS、community 或故障检测。
