# 基于小型 RIB 图的锚点选择实验

## 运行

先按 `results/rib_replay/README.md` 生成状态变化文件。依赖 Python 3.9、mrtparse 2.2.0、networkx 3.2.1、numpy 1.26.4。在 coding 文件夹运行：

```sh
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m unittest discover -s tests -v
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python src/topology_anchor.py
```

默认最多选择 6 个互不重叠的事件，事件候选关联窗口 100 秒。结果写在本目录 `summary.json`、`features.jsonl`；重新运行会覆盖它们。

## 实现和本次结果

从已有的 20 个 IPv4 前缀 RIB 初始化每个 VP 的链路计数，读取 15 分钟的状态变化。某个 VP 的定向链路权重从 0 变为正数或反向变化时形成候选观察；相同方向、同种类型和 100 秒内的观察聚成候选事件，保留被少于半数 VP 观察到的事件。按观察 VP 数优先选择互不重叠的候选事件。逐事件、逐 VP 保存开始秒之前和结束秒之后的图状态，计算两端 AS 的 6 项点特征及 3 项节点对特征之差，形成 15 维向量。对每个事件的每列特征按全部 VP 标准化，计算两两欧氏距离并跨事件平均；缩放成冗余分数后，按论文的首选中心 VP、10% 候选、低数据量原则选择锚点。

本次找到 7,341 个候选事件，选出 6 个，54 个 VP 中选出 50 个锚点；共输出 324 条 15 维特征。候选事件和锚点非常依赖小样本及停止条件；50 不代表真实网络或论文结果。事件覆盖 00:00—00:15 的观察区间，包含先前 00:10 测试窗口，因此不能把它与先前过滤测试组合起来宣称独立测试结果。

## 与论文的关键区别

- 图仅包含 20 个选定前缀，不是每个 VP 的完整 RIB。
- 仅用链路出现/消失，不含 origin change；未按 AS 类别、事件种类和时间均衡抽样，也没有论文使用的 2,250 个事件。候选按可见 VP 数优先选择会引入偏差。
- 论文图为加权有向图；本原型把两个方向的权重加总后转成无向图，方便使用 NetworkX 的节点对特征。它丢失方向信息。
- 把链路路由数视作强度，计算最短路径时距离取强度倒数；不可达节点不参与距离统计，缺失节点记为 0。这些是原型约定，不保证与论文作者实现一致。
- 锚点选择使用 15 分钟里产生状态变化的消息数估计负载，并非论文跨 365 天的一小时采样；距离及 10% 候选机制按论文框架实现，但还须与原作者代码或详细图定义校验。
- 不支持的路径、解析错误和未处理 peer 重置可影响结果。只处理 20 个前缀也让此处“链路出现或消失”未必是完整 RIB 中真正的图变化。
- 当前只是锚点算法的研究原型，尚未将锚点用于独立时间的过滤效果评估，不可称为完整 GILL 复现。
